# Screenshots

Save capture files in this folder using the exact names below so the main README embeds work.

| File | Page | Suggested frame |
|---|---|---|
| `dashboard.png` | `/` | KPI row plus pending approvals / out today |
| `employees.png` | `/employees` | Add form, org structure, and part of the directory |
| `leave.png` | `/leave` | Request form and queue (include an overdue or pending row if possible) |
| `payroll.png` | `/payroll` | Generate form, period list, and payslips for a selected period |

Tips:
- Run the seeded app (`flask seed` then `python run.py`) so the panels have real data.
- Use a desktop browser width (~1280px) so the sidebar layout shows.
- Optional: add `dashboard-mobile.png` for a narrow viewport if you want a mobile shot; it is not linked in the README by default.
